# 🖥️ Ferramentas de Suporte TI
Ferramentas de diagnóstico e automação para suporte técnico em TI, desenvolvidas em Python.

Projeto desenvolvido em Python com o objetivo de criar ferramentas para diagnóstico, monitoramento básico e automação de tarefas relacionadas ao suporte técnico em Tecnologia da Informação.

## 🎯 Objetivo

Desenvolver uma aplicação que auxilie profissionais de suporte técnico na identificação de problemas comuns em computadores e redes.

## ⚙️ Funcionalidades

- [ ] Identificação de informações do sistema operacional.
- [ ] Consulta de informações do computador.
- [ ] Verificação de conectividade com a internet.
- [ ] Identificação do endereço IP.
- [ ] Testes de conectividade com servidores.
- [ ] Geração de relatórios de diagnóstico.

## 🛠️ Tecnologias utilizadas

- Python 3
- Biblioteca `platform`
- Biblioteca `socket`
- Biblioteca `subprocess`
- Git e GitHub
